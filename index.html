Bagian 01

Latar Belakang

Dalam analisis medis modern, proses pemindaian kesehatan pasien seperti pengukuran volume tidal dan analisis spirometri kerap harus memproses jutaan titik grafik pernapasan setiap harinya. Volume data tersebut menghasilkan tekanan komputasi yang sangat besar pada sistem.

Metode pemrosesan sequential konvensional (di mana satu core memproses satu baris data dalam satu waktu) seringkali memicu bottleneck yang signifikan, sehingga menunda deteksi anomali dan berpotensi membahayakan kondisi pasien secara keseluruhan.

Solusi yang Diusulkan

Proyek ini memanfaatkan modul multiprocessing bawaan Python untuk mendistribusikan beban kerja inspeksi grafik ke seluruh logical core yang tersedia, sehingga pemrosesan berlangsung secara konkuren dan paralel (bukan lagi satu-per-satu).

N×

Percepatan teoritis dengan N core paralel dibanding sequential

Batch

Grafik diproses dalam kelompok parallel chunks, bukan baris per baris

Real-time

Deteksi anomali pernapasan yang lebih cepat dan responsif

Bagian 04

Analisis Performa

Pengujian dilakukan dengan mensimulasikan inspeksi sejumlah batch grafik pernapasan. Setiap titik grafik dianalisis untuk mendeteksi indikator anomali pernapasan. Hasil pengukuran latensi dibandingkan antara pendekatan sequential dan paralel.

Metrik Sequential (1 Node) Paralel (Multi-node) Kesimpulan
Jumlah Core 1 Node N Core (semua tersedia) Tergantung Mesin
Strategi Pemrosesan Baris per baris (satu per satu) Chunk paralel konkuren ✔ Paralel Lebih Efisien
Latensi pada Data Besar Tinggi (linear terhadap N data) Rendah (dibagi N core) ✔ Paralel Lebih Cepat
Risiko Bottleneck Tinggi Sangat Rendah ✔ Paralel Lebih Aman
Skalabilitas Tidak skalabel Linear terhadap jumlah core ✔ Paralel Lebih Baik
Overhead Minimal Ada (proses spawn) ⚠ Sequential Lebih Ringan
Catatan Penting: Overhead vs. Speedup

Pendekatan paralel membawa overhead berupa waktu inisiasi proses (spawn time). Untuk dataset kecil, overhead ini bisa membuat pemrosesan paralel justru lebih lambat. Keunggulan paralel baru terlihat signifikan pada dataset besar (ribuan hingga jutaan titik grafik).

Bagian 05

Instruksi Eksekusi

Ikuti langkah-langkah berikut untuk menjalankan simulasi perbandingan performa sequential vs. paralel secara lokal di mesin Anda.

  • Pastikan Python 3.x Terinstall

    Unduh dan pasang Python 3.8 atau lebih baru dari python.org. Modul multiprocessing sudah termasuk di Python Standard Library, tidak perlu instalasi paket tambahan.

  • Clone atau Unduh Repositori

    Buka terminal / command prompt lalu jalankan perintah berikut untuk mengunduh kode sumber dari GitHub:

  • Navigasi ke Direktori Proyek

    Masuk ke folder repositori yang sudah diunduh, pastikan file main.py tersedia di direktori aktif Anda.

  • Jalankan Simulasi

    Eksekusi skrip utama dengan perintah di bawah. Program akan secara otomatis menjalankan kedua pendekatan dan menampilkan perbandingan latensi di terminal:

Terminal  —  bash / cmd / powershell

# 1. Clone repositori
git clone https://github.com/Lifyhzz/Respiratory-Inspection.git
cd Respiratory-Inspection

# 2. Jalankan simulasi
python main.py
