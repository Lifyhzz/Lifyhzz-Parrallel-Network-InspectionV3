[Instruksi Eksekusi](#4-instruksi-eksekusi) --- ## 1. Latar Belakang 🌐 Dalam manajemen jaringan dan telekomunikasi, melakukan pemindaian keamanan (*vulnerability assessment* atau *packet sniffing*) terhadap jutaan baris *log traffic* membutuhkan daya komputasi yang masif. Metode pemrosesan sekuensial konvensional seringkali memicu **bottleneck** yang menunda deteksi anomali. Proyek ini mendemonstrasikan efisiensi komputasi paralel menggunakan modul `multiprocessing` pada Python untuk mempercepat inspeksi *batch log* jaringan secara *real-time*. ## 2. Desain Arsitektur Sistem 🏗️ Beban pemrosesan *log* didistribusikan secara merata ke seluruh *core logical* yang tersedia pada *server*, memecah antrean data menjadi beberapa eksekusi konkuren. ```mermaid graph TD A[Dataset: Batch Log Jaringan] --> B{Sistem Inspeksi} B -->|Cara Lama| C[Sekuensial: 1 Core membaca baris per baris] B -->|Cara Baru| D[Paralel: Pool Multiprocessing] D --> E[Worker 1] D --> F[Worker 2] D --> G[Worker 3] E & F & G --> H[Agregasi Status Keamanan] C -.-> I[Deteksi Lambat / Bottleneck ⚠️] H -.-> J[Deteksi Real-time & Cepat ⚡] ``` ## 3. Analisis Performa ⚡ Berdasarkan komputasi dari dataset *log*, hasil performa dapat diuji untuk membandingkan perbedaan kecepatan pemrosesan sekuensial dan paralel. **Pemrosesan paralel jauh lebih unggul** dalam memangkas waktu saat menangani data bervolume tinggi, menjaga kecepatan deteksi tetap stabil pada jaringan waktu nyata (*real-time processing*). ## 4. Instruksi Eksekusi 💻 Berikut ini adalah langkah-langkah untuk menjalankan simulasi: 1. Pastikan **Python 3.x** telah terinstall di sistem operasi Anda. 2. Buka terminal atau *command prompt*, lalu navigasikan ke direktori repositori ini. 3. Jalankan sintaks berikut: ```bash python main.py ``` 4. Hasil keluaran di terminal akan menampilkan perbandingan latensi antara inspeksi sekuensial dan paralel.
